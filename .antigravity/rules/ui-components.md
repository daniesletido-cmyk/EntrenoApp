# Skill: UI Components & Visual Polish
- Estilo visual: Tarjetas elevadas con fondo sutil, bordes translúcidos (`border border-white/10`) y esquinas amplias (`rounded-2xl`).
- Componentes base: Si se requieren botones, desplegables, diálogos o pestañas, priorizar componentes tipo Shadcn/Radix.
- Estados de interacción: Transiciones suaves (`transition-colors duration-150`), hover y foco accesible.
- Paleta: Fondo oscuro limpio, tarjetas elevadas y verde esmeralda (#10B981) como acento atlético.
