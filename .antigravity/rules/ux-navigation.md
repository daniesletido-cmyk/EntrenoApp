# Skill: UX & Navigation Hierarchy
- Menú móvil: `BottomNav` con máximo 5 accesos, efecto blur translúcido (`backdrop-blur-md`) e indicador claro en la pestaña activa.
- Cargas: Prohibido texto plano como "Cargando...". Usar siempre Skeleton loaders con `animate-pulse`.
- Notificaciones: Usar toasts flotantes para confirmaciones de guardado o registro.
